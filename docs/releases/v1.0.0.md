# Guichê v1.0.0

## Status

Release estável.

## O que a v1.0 representa

A v1.0.0 é a primeira linha estável do Guichê como Core PHP genérico para assistentes conversacionais orientados a Tools, Plugins, estado, segurança, persistência e runtime.

O piloto clínico permanece apenas como exemplo avançado de domínio.

## Contrato estável

A API `public` contém 24 símbolos protegidos pela política SemVer/BC.

SHA-256 da superfície pública:

`39e417149aaee5ac9008de4bb3e477c579826f86ea9902b8755965fc1482368d`

## Experimental

Os 11 símbolos do Conversation Runtime permanecem `experimental`.

Eles são funcionais e testados, mas não fazem parte do compromisso BC da linha v1.x até promoção explícita.

## Compatibilidade

- PHP 8.4: suportado;
- PHP 8.5: suportado;
- Composer package: `asmpkg/guiche`;
- package type: `library`.

## Segurança

A linha v1 preserva:

- hard execution gate imediatamente antes de `ToolInterface::execute()`;
- Tool call como solicitação, nunca autorização;
- WRITE sem cache/retry genérico;
- replay/idempotência explícita;
- Result Projection;
- observabilidade com redaction;
- pacote distribuível sem `.env`, storage, vendor ou artefatos internos.

## Evidência de consumidor externo

A v0.9.0 publicada foi instalada em projeto Composer externo, sem symlink/path repository, e validou:

- Plugin externo;
- Tool WRITE externa;
- provider externo;
- ContextStore público;
- bloqueio por precondition;
- execução autorizada;
- replay idempotente sem side effect duplicado.
