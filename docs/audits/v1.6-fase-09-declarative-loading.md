## Entrega

Nova API pública aditiva:

```php
GuicheBuilder::loadCapabilities(array $definition): self
```

Formato:

```php
[
    'services' => [
        Interface::class => $service,
    ],
    'tools' => [
        'MinhaTool',
        MinhaTool::class,
    ],
    'plugins' => [
        'MeuPlugin',
        MeuPlugin::class,
    ],
]
```

## Princípios

- nenhum novo container;
- nenhum novo Composition Root no Core;
- nenhum discovery implícito de filesystem;
- nenhuma factory mágica de services;
- reutiliza `ServiceRegistry`;
- reutiliza `ClassResolver`;
- reutiliza `loadTool(s)`;
- reutiliza `loadPlugin(s)`;
- mantém APIs imperativas de baixo nível.

## Ordem

```text
services -> tools -> plugins
```

## Preflight

Antes de publicar a declaração:

- estrutura completa é validada;
- chaves desconhecidas são rejeitadas;
- services precisam ser objetos;
- tools/plugins precisam ser listas de strings;
- ServiceRegistry temporário é montado;
- classes são resolvidas;
- construtores são resolvidos;
- contratos Tool/Plugin são validados;
- conflitos diretos são detectados.
