# Guichê v1.6.0 — Fase 04: Trusted Parameter Binding

## Objetivo

Permitir que argumentos operacionais de uma Tool sejam resolvidos de fontes
confiáveis e não fiquem sob controle da IA.

## Contrato

Metadados de `ToolRegistration`:

```php
'trusted_parameters' => [
    'empresa_id' => [
        'source' => 'context',
        'path' => 'tenant_id',
        'visible' => false,
    ],
],
```

Fontes implementadas:

- `ai`;
- `context`;
- `fixed`;
- `config`;
- `service`.

## Garantias

1. `visible=false` remove o parâmetro da definição enviada à IA.
2. O schema original da Tool não é alterado.
3. Binding ocorre antes do `ToolExecutionGate`.
4. Binding ocorre novamente antes da execução real.
5. Valores forjados pela IA são sobrescritos.
6. Gate valida os argumentos efetivos.
7. Cache/fingerprint/idempotência usam os argumentos efetivos.
8. `StateManager::onToolResult()` recebe os argumentos efetivos.
9. Falta de valor confiável bloqueia em fail-closed.
10. Tools sem binding mantêm comportamento legado.

## Compatibilidade de API

A implementação adiciona somente:

`Asmpkg\Guiche\Safety\TrustedParameterBinder`

classificado como `internal`.

Nenhuma assinatura pública da v1 foi alterada e o hash público deve permanecer
compatível com o baseline vigente.
