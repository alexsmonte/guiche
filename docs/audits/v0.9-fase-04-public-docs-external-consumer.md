## Safety acceptance

A Tool externa `PublishCatalogItem` foi registrada como WRITE com:

```php
'requires_state' => ['state.release_approved']
```

Sem esse estado, o provider recebeu `required_state_missing` e o contador de side effects permaneceu em zero.

Com o estado presente, a Tool executou uma vez. Repetindo a mesma WRITE na mesma sessão com os mesmos argumentos, o ContextStore externo devolveu o resultado persistido e o side effect não foi repetido.
