# Guichê v1.5.0 — Loaders, DI e Tenant Prompts

Release estável preparada em 16/10/2026.

## Entregas

- `ServiceRegistry`;
- `ClassResolver` interno por Reflection;
- `GuicheBuilder::setService()`, `hasService()` e `getService()`;
- `loadTool()` / `loadTools()`;
- `loadPlugin()` / `loadPlugins()`;
- nomes curtos por `App\Tool` e `App\Plugin`;
- FQCN nos loaders;
- `TenantPromptResolver`;
- `prompts/comportamento.md + prompts/{tenant_id}.md`;
- Composition Root com `services`, Tools e Plugins por string;
- `init` com estrutura PSR-4 do consumidor;
- `doctor` com validação de prompt e PSR-4.

## Compatibilidade

Continuam preservados:

- `registerTool()`;
- `registerPlugin()`;
- `ToolInterface`;
- `PluginInterface`;
- `ContextStoreInterface`;
- `AiProviderInterface`;
- `withInstructions()`;
- resolvers da v1.4;
- `guiche.prompt.md` legado.

## Segurança

```text
bootstrap confiável
→ loadTool/loadPlugin
```

Nunca:

```text
usuário/IA
→ nome PHP
→ loader
```

E o prompt multi-tenant continua usando:

```text
bindIdentity()
→ TenantResolver
→ tenant_id confiável
→ PromptContext
→ TenantPromptResolver
```
