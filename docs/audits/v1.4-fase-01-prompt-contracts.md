# Guichê v1.4.0 — Fase 01 — Prompt Resolution Contracts

## Baseline

- `main`: `ca0b8e2297ed677e03c704979119d12deeed145f`
- release anterior: `v1.3.0`
- branch: `feature/v1.4.0-dynamic-prompt-composition`

## Objetivo

Criar o contrato público mínimo para resolução dinâmica de prompts sem alterar
ainda o fluxo de `Guiche::handle()`, o `GuicheBuilder` ou a Safety Layer.

## Arquitetura

```text
SESSION
  ↓
execution_context confiável
  ↓
PromptContext
  ↓
PromptResolverInterface
  ↓
string de instruções
```

O resolver poderá futuramente buscar o prompt em:

- arquivo;
- banco;
- API;
- cache/CMS;
- composição de fontes;
- callback/closure da aplicação.

## Decisões desta fase

1. `PromptResolverInterface` é API pública v1.4.
2. A assinatura pública é:
   `resolve(PromptContext $context): string`.
3. `PromptContext` também é API pública.
4. `PromptContext` é genérico e não conhece Chatwoot, clínica ou framework.
5. `PromptContext` contém `sessionId` + mapa de valores confiáveis.
6. `tenant_id` possui accessor explícito para o caso multi-tenant.
7. Mensagem do usuário, resposta da IA e argumentos livres de Tool não fazem
   parte do contrato de seleção do prompt.
8. O atual `Asmpkg\Guiche\Cli\PromptResolver` continua interno e intacto.
9. `GuicheBuilder::withInstructions()` permanece intacto nesta fase.
10. Nenhuma mudança de comportamento do runtime é introduzida aqui.

## Roadmap v1.4.0

1. **Fase 01 — Baseline + Prompt Contracts** — esta fase.
2. **Fase 02 — Runtime Prompt Resolution** — adapter de closure, resolvers base,
   integração compatível no `GuicheBuilder` e resolução por sessão/tenant.
3. **Fase 03 — guiche.php Composition Root** — configuração oficial e livre de
   framework para AI, storage, tenant, prompts, Tools e Plugins.
4. **Fase 04 — Prompt Sources** — arquivo, callback, composição e exemplos de
   banco/API sem acoplamento de domínio.
5. **Fase 05 — Multi-tenant + Security + Framework Integration** — isolamento,
   precedência, concorrência, adapters e regressão completa.
6. **Fase 06 — Docs + API Freeze + Release** — README, migração, changelog,
   clean install, acceptance, tag `v1.4.0`.

## Critério de encerramento

A Fase 01 fecha somente se:

- os dois novos símbolos públicos estiverem no stability map;
- PHPUnit específico estiver verde;
- PHPStan/coverage/regressões continuarem verdes;
- API baseline v1 for atualizado explicitamente;
- `composer84 check` passar;
- nenhuma assinatura pública v1.3 for removida ou alterada.
