# Guichê v1.4.0 — Dynamic Prompt Composition

Release estável preparada em 16/10/2026.

## Entregas

- `PromptResolverInterface` e `PromptContext`;
- Closure/callback;
- Static/File/Fallback PromptResolver;
- resolução uma vez por turno;
- `guiche.php` Composition Root;
- prompts por tenant confiável;
- fontes arquivo/repository/API;
- integração CakePHP/Laravel/Symfony/PHP puro.

## Segurança

```text
SESSION → bindIdentity() → TenantResolver → tenant_id
→ PromptContext → PromptResolver → prompt
```

Mensagem/state/argumentos de Tool não selecionam tenant. Rebinding conflitante
falha fechado. Exceptions de fonte não são mascaradas por fallback.
Observabilidade não registra raw identity, tenant ou prompt.

## Compatibility

Release SemVer minor aditiva. `withInstructions()`, `ToolInterface`,
`ContextStoreInterface`, `TenantResolverInterface` e `bindIdentity()` continuam
compatíveis.
