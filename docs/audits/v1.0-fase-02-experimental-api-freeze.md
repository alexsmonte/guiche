# GUICHÊ v1.0.0 — Fase 02 — Experimental API Decision + Freeze

## Decisão

Os **11 símbolos Experimental atuais permanecem Experimental na v1.0.0**.

Eles continuam disponíveis para consumidores avançados, porém **não fazem parte do compromisso de backward compatibility da API pública v1.x**.

Nenhum símbolo foi promovido para Public nesta fase.

## Motivo

A superfície Experimental concentra o Conversation Runtime, que já é funcional e testado, mas ainda possui maior probabilidade de evolução de ergonomia, lifecycle e persistência do que o Core público congelado.

Promover toda essa superfície agora criaria um compromisso BC prematuro e ampliaria desnecessariamente a área estável da v1.0.

## Símbolos congelados

- `Asmpkg\Guiche\Conversation\ConversationKey`
- `Asmpkg\Guiche\Conversation\ConversationRuntime`
- `Asmpkg\Guiche\Conversation\ConversationTurn`
- `Asmpkg\Guiche\Conversation\FollowUpScheduler`
- `Asmpkg\Guiche\Conversation\IncomingEvent`
- `Asmpkg\Guiche\Conversation\IncomingEventRecorder`
- `Asmpkg\Guiche\Conversation\JsonConversationStore`
- `Asmpkg\Guiche\Conversation\JsonScheduledEventStore`
- `Asmpkg\Guiche\Conversation\MessageBuffer`
- `Asmpkg\Guiche\Conversation\ScheduledEventRunner`
- `Asmpkg\Guiche\Conversation\Scheduler`

## Exceção importante

`Asmpkg\Guiche\Conversation\ScheduledEvent` **não é Experimental**. Ele já é Public porque é exposto transitivamente por contratos públicos.

## Enforcement

Foram adicionados:

- `api/experimental-v1.json` — baseline explícito dos símbolos Experimental;
- `tools/check-experimental-api.php` — checker da lista/classificação;
- `composer check-experimental-api`;
- integração do checker ao `composer check`.

Freeze SHA-256 do arquivo Experimental:

`e3898425e5db74e8c2537770d80fcf178c99a843ddc056f6120de98b600f0913`

## Regra de promoção

Promover um símbolo Experimental para Public exige:

1. decisão explícita de API;
2. revisão SemVer;
3. atualização do `api/stability-map.php`;
4. atualização deliberada do baseline público;
5. atualização deliberada do freeze Experimental;
6. CI verde em PHP 8.4 e PHP 8.5.

P1-001 — decisão explícita sobre os 11 símbolos Experimental: **RESOLVED**.
