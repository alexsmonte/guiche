# Guichê v1.1.0 — Fase 04 — Contextual Runtime

Fluxo conectado:

```text
SESSION
  ↓
ContextStore
  ↓
execution_context.identity
  ↓
TenantResolver
  ↓
execution_context.tenant_id
  ↓
ToolExecutionContext
  ↓
ContextAwareToolInterface::executeWithContext()
```

## Compatibilidade

Tools legadas continuam usando:

```text
ToolInterface::execute(array $arguments)
```

Tools contextuais usam:

```text
ContextAwareToolInterface::executeWithContext(
    array $arguments,
    ToolExecutionContext $context
)
```

`ToolRegistry::execute()` e `PresentedTool` permanecem inalterados.

## Segurança

Para ContextAware Tools, o tenant precisa estar pronto antes de
READ cache ou WRITE replay.

Antes da execução real, Gate 2 e o contexto de tenant são
revalidados.

Argumentos da IA não são a fonte autoritativa de tenant.
O tenant efetivo vem de `ToolExecutionContext::tenantId()`.

## Presenter

O Builder usa:

```text
Tool legada + Presenter
    → PresentedTool

ContextAware Tool + Presenter
    → ContextAwarePresentedTool
```

Assim, adicionar Presenter a uma Tool antiga não a transforma em
Tool contextual.

## API v1.1

Nova configuração compatível:

```php
$builder->withTenantResolver($resolver);
```

O construtor do `Guiche` também aceita o parâmetro opcional
`tenantResolver`.

## Fail closed

ContextAware Tool não executa sem:

- sessionId;
- identity confiável;
- tenant válido.

Falha do resolver não alcança a Tool.

## Preservado

- Gate 1;
- Gate 2;
- READ cache;
- WRITE replay/idempotência;
- Result Projection;
- observabilidade;
- Tools legadas.
