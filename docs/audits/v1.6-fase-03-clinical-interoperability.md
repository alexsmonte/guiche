# Guichê v1.6.0 — Fase 03: Clinical Interoperability

## Objetivo

Integrar o estado clínico do exemplo do Guichê com nomes e formatos de Tools
observados em consumidores reais, sem duplicar a responsabilidade de transporte
e sem criar uma segunda WRITE concorrente.

## Evidências usadas

Foram observados dois contratos de consulta de paciente:

- `ConsultarPaciente`, usado pelo exemplo clínico atual;
- `ConsultaPaciente`, usado por consumidor externo.

Também foi observado `CadastrarPaciente` com:

- `cpf`;
- `nome_completo`;
- `data_nascimento`;
- `email` opcional;
- `endereco`;
- `celular`.

O retorno de cadastro pode fornecer `novo_paciente_id`.

O documento de StateManager também prevê `AgendarConsulta` depois que o estado
de paciente estiver resolvido.

## Decisões

### 1. Não duplicar CriarAgendamento

O exemplo atual já possui `CriarAgendamentoTool` como WRITE, com:

- Safety Layer;
- confirmation gate;
- slot revalidation;
- idempotência;
- Result Projection.

Por isso a Fase 03 NÃO registra uma segunda WRITE chamada `AgendarConsulta`.

O StateManager apenas passa a compreender resultados de:

- `AgendarConsulta`;
- `agendarConsulta`;

caso uma aplicação consumidora registre uma dessas Tools externamente.

### 2. CadastrarPaciente permanece Tool externa

O Core e o exemplo não inventam endpoint, procedure ou transporte de cadastro.

O StateManager apenas persiste o fato retornado por uma Tool externa
`CadastrarPaciente`.

### 3. CPF não é descartado quando o paciente não existe

A consulta sem cadastro agora preserva o CPF informado e registra:

- `paciente_cadastrado = false`;
- `paciente_nao_encontrado = true`;
- `status = paciente_nao_cadastrado`.

IDs anteriores de paciente/agendamento são invalidados.

## Compatibilidade entregue

- `ConsultarPaciente`;
- `ConsultaPaciente`;
- `CadastrarPaciente`;
- `CriarAgendamento`;
- `AgendarConsulta`;
- `agendarConsulta`.

Falhas de Tool continuam sem produzir patch de estado.

## Fronteira

Nenhum arquivo de `src/` genérico é alterado.

Trusted Parameter Binding permanece para a Fase 04.
