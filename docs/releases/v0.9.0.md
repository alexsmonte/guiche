# Guichê v0.9.0 — Release Candidate

A v0.9.0 transforma o trabalho acumulado desde o piloto em uma **Release Candidate de biblioteca genérica** preparada para estabilização em v1.0.0.

## O que esta versão prova

Um projeto externo consegue instalar `asmpkg/guiche`, configurar seu próprio `AiProviderInterface`, registrar Tools e Plugins, trocar o `ContextStoreInterface`, persistir estado e usar a Safety Layer sem editar o Core e sem conhecer o domínio clínico.

## Superfície pública candidata à v1

A API foi classificada e congelada:

- 24 símbolos Public;
- 11 Experimental;
- 11 Internal.

Mudanças incompatíveis na superfície Public passam a falhar no checker de BC integrado ao `composer check`.

## Segurança

A v0.9 mantém como invariantes:

- AI Tool calls são pedidos, não autorização;
- toda execução passa pelo hard execution gate;
- WRITE não recebe retry/cache genérico;
- replay WRITE usa idempotência explícita;
- result projection reduz exposição de payloads;
- runtime events não devem armazenar payload bruto sensível.

A revisão da RC também adiciona uma política pública de segurança e uma CI de menor privilégio.

## Persistência, observabilidade e Conversation Runtime

O Core já inclui:

- Context Store abstrato e backend JSON atômico;
- locks, temp + rename e schema versionado;
- Runtime Event Sink e JSONL;
- eventos correlacionáveis e redigidos;
- incoming event dedupe;
- sequence/version;
- message buffer e turn snapshots;
- quiet/max turn windows;
- durable scheduler;
- leases/fencing;
- stale protection;
- follow-up/recovery.

As APIs de Conversation marcadas como Experimental ainda não recebem a mesma promessa de compatibilidade da superfície Public.

## Distribuição

A Release Candidate inclui:

- Composer package limpo;
- documentação pública;
- exemplo básico neutro;
- exemplo clínico avançado isolado;
- `CHANGELOG.md`;
- `SECURITY.md`;
- release notes;
- manifestos e checksums.

Arquivos de desenvolvimento, `.env`, storage, tools internos, testes e auditorias internas não entram no pacote distribuído.

## PHP

- constraint: `^8.4`;
- matriz da RC: PHP 8.4 e 8.5.

O aceite local foi executado em PHP 8.4. A publicação final depende do GitHub Actions confirmar também o runtime PHP 8.5.
