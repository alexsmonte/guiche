# Guichê v1.4.0 — Fase 03 — `guiche.php` Composition Root

## Objetivo

Fornecer um ponto único, explícito e framework-agnostic para compor o
runtime do Guichê no projeto consumidor.

## Decisão principal

`config/guiche.php` do pacote permanece como configuração de dados
legada/genérica e não muda de contrato nesta fase.

O novo Composition Root é:

```text
<projeto consumidor>/guiche.php
```

Ele é criado por:

```bash
vendor/bin/guiche init
```

e nunca é sobrescrito quando já existe.

## Contrato do arquivo

`guiche.php` retorna uma factory callable:

```php
$factory = require __DIR__ . '/guiche.php';
$guiche = $factory();
```

A factory retorna obrigatoriamente:

```text
Asmpkg\Guiche\Guiche
```

## Dependências compostas

O Composition Root pode configurar/substituir:

- `AiProviderInterface`;
- `ContextStoreInterface`;
- `TenantResolverInterface`;
- `PromptResolverInterface` ou `Closure`;
- `RuntimeContext`;
- Tools;
- Plugins;
- instruções estáticas adicionais;
- agent context;
- reusable tools;
- history limit;
- max tool rounds;
- callback final `configure`.

## Prompt padrão

O resolver padrão do Composition Root usa a prioridade:

```text
GUICHE_PROMPT_FILE
→ GUICHE_PROMPT
→ <projeto>/guiche.prompt.md
```

O prompt é lido em runtime, por turno.

## Compatibilidade

Projetos anteriores que não possuem `guiche.php` continuam usando o
bootstrap interno legado da CLI.

Assim, a v1.4 adiciona o Composition Root sem tornar sua existência
obrigatória para projetos v1.3 já instalados.

## Frameworks

O arquivo não depende de Laravel, Symfony, CakePHP ou outro framework.

A aplicação pode carregar a factory e fornecer objetos do seu container
através do array de overrides.

## Segurança

O Composition Root não recebe a mensagem do usuário para escolher
dependências ou prompt.

A resolução dinâmica de prompt continua usando `PromptContext`,
`execution_context` e tenant confiável conforme a Fase 02.

## Aceite da fase

- template oficial existe em `resources/guiche.php`;
- `guiche init` cria `guiche.php`;
- arquivo existente nunca é sobrescrito;
- CLI prefere o Composition Root quando ele existe;
- CLI antiga continua funcional sem `guiche.php`;
- AI, ContextStore, TenantResolver, PromptResolver, Tools e Plugins
  podem ser compostos no arquivo;
- Composition Root retorna `Guiche`;
- API pública de `src/` não é alterada nesta fase;
- quality gate completo permanece verde.
