## P1 — necessários antes de declarar v1.0 estável

### P1-001 — decisão explícita sobre os 11 símbolos Experimental

Cada símbolo Experimental deve permanecer explicitamente experimental ou ser promovido à superfície Public com baseline correspondente.

### P1-002 — feedback da Release Candidate

Executar a v0.9 em pelo menos um consumidor real/representativo além dos acceptances automatizados e registrar incompatibilidades de DX/API encontradas.

### P1-003 — fechamento final da documentação v1

Revisar README, Quick Start, API Stability, PHP Support, Security e migration/release notes para remover linguagem de RC e refletir a política estável da v1.

## Critério para v1.0

A v1.0 só deve ser publicada quando:

- P0 = 0;
- os P1 acima estiverem resolvidos ou formalmente aceitos com decisão documentada;
- API Public continuar compatível com o baseline candidato;
- CI suportada estiver verde;
- pacote público continuar limpo e instalável por Composer.
