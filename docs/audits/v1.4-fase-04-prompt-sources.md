# Guichê v1.4.0 — Fase 04 — Prompt Sources

## Objetivo

Oferecer fontes reutilizáveis de prompt sobre
`PromptResolverInterface`, removendo lógica de leitura de prompt do
Composition Root e mantendo banco/API fora do Core.

## API pública adicionada

- `StaticPromptResolver`
- `FilePromptResolver`
- `FallbackPromptResolver`

`CallbackPromptResolver` já havia sido criado na Fase 02.

## Fontes suportadas

### Inline / memória

`StaticPromptResolver`

### Arquivo

`FilePromptResolver`

O arquivo é lido em cada `resolve()`, portanto mudanças podem ser
aplicadas entre turnos sem reconstruir `Guiche`.

### Banco / Repository

`CallbackPromptResolver`

O Core não recebe dependência de PDO, ORM ou schema de prompt.

### API / CMS

`CallbackPromptResolver`

O Core não recebe dependência de cliente HTTP ou protocolo específico.

### Fallback

`FallbackPromptResolver`

A cadeia avança apenas quando uma fonte retorna string vazia.

Exceptions não são capturadas.

## Regra fail-closed

```text
sem configuração
→ resolver pode retornar ""
→ fallback permitido

falha operacional/segurança
→ exception
→ propaga
→ fallback proibido
```

Isso impede que timeout, banco indisponível, erro HTTP ou problema de
autorização alterem silenciosamente o comportamento operacional do
agente.

## Composition Root

`resources/guiche.php` passa a usar:

- `FilePromptResolver` para `GUICHE_PROMPT_FILE`;
- `StaticPromptResolver` para `GUICHE_PROMPT`;
- `FilePromptResolver` para `guiche.prompt.md`.

A função global `readGuichePrompt()` da Fase 03 é removida.

## Multi-tenant

Resolvers externos podem usar somente os dados disponíveis em
`PromptContext`, inclusive `tenant_id` resolvido pela fronteira
confiável.

Mensagem do usuário, output da IA e argumentos livres de Tool não são
fontes de seleção de prompt.

## Aceite da fase

- prompt estático validado;
- prompt em arquivo relido por turno;
- arquivo ausente/vazio falha fechado;
- callback pode representar banco/API;
- fallback ocorre apenas para resultado vazio;
- exception de fonte não é mascarada;
- tenant pode selecionar fonte via `PromptContext`;
- Composition Root usa as fontes públicas;
- API freeze atualizado explicitamente;
- quality gate completo verde.
