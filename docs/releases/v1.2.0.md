# Guichê v1.2.0

## Status

Release estável preparada em 15/10/2026.

## Objetivo

A v1.2.0 transforma a primeira experiência do Guichê em um fluxo Composer + CLI
sem exigir que o desenvolvedor copie ou crie manualmente `chat.php`.

## CLI pública

Após instalar:

```bash
composer require asmpkg/guiche:^1.2
```

o consumidor recebe:

```bash
vendor/bin/guiche
```

Comandos:

```text
help
init
doctor
chat
usage
```

## Bootstrap automático

```bash
vendor/bin/guiche init
```

cria no projeto consumidor:

```text
.env
guiche.prompt.md
storage/conversations/
```

O comando é idempotente e não sobrescreve configuração existente.

## Chat

Interativo:

```bash
vendor/bin/guiche chat
```

Mensagem única:

```bash
vendor/bin/guiche chat "Olá"
```

Sessão explícita:

```bash
vendor/bin/guiche chat --session=cliente-123 "Olá"
```

Comandos locais do modo interativo:

```text
/context
/usage
/tools
/reset
/sair
```

## Prompt configurável

Prioridade:

```text
1. GUICHE_PROMPT_FILE
2. GUICHE_PROMPT
3. guiche.prompt.md
4. resources/guiche.prompt.md
```

O prompt padrão deixa de ficar embutido na lógica da CLI e passa a ser um
recurso distribuído pelo pacote.

## Diagnóstico

```bash
vendor/bin/guiche doctor
```

verifica PHP, extensões, ambiente, modelo e storage sem fazer chamada de teste ao
provider.

## Compatibilidade

A v1.2.0 não altera a superfície pública congelada da linha v1.

No fechamento:

- Public: 32;
- Experimental: 11;
- Internal: 14;
- SHA-256 da API pública:
  `f4328ccc4724f0e097e0d9369329a6bb3bbfe27bca5cddc8d452f43a63130c41`.

`Asmpkg\Guiche\Cli\Application` e
`Asmpkg\Guiche\Cli\PromptResolver` são `internal`.

## Segurança

A CLI utiliza `GuicheBuilder` e o runtime normal.

A v1.2 preserva:

- Tool call da IA como solicitação, nunca autorização;
- Tool Policy;
- hard execution gate antes de side effects;
- READ cache separado de WRITE replay;
- WRITE sem retry/cache genérico;
- idempotência;
- Result Projection;
- contexto multi-tenant confiável.

## Aceite externo

A implementação final foi instalada em projeto Composer vazio como
`asmpkg/guiche 1.2.0`, com cópia física em `vendor/`, sem symlink.

Foram validados:

- `vendor/bin/guiche`;
- `help`;
- `init`;
- init idempotente;
- `doctor`;
- bootstrap do `chat`;
- prompt personalizado do consumidor;
- conversa completa com `AiProviderInterface` externo/fake;
- persistência em `storage/conversations`;
- `usage`;
- isolamento entre package e projeto consumidor.
