## Security invariants

- identity write-once;
- tenant write-once;
- tenant não controlado pela IA;
- ContextAware sem session bloqueia;
- missing/unresolved tenant bloqueia;
- nenhuma WRITE contextual executa sem contexto;
- resolver failure fail-closed;
- Gate 1 / Gate 2 preservados;
- WRITE sem retry cego;
- replay idempotente preservado.
