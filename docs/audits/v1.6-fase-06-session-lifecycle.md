# Guichê v1.6.0 — Auditoria da Fase 06

## Fase

Session Lifecycle — TTL + `first/new/active/expired`.

## Baseline

Fase 05 concluída:

## Origem da necessidade

Backlog do StateManager:

```dotenv
GUICHE_SESSION_TTL=86400
```

API desejada:

```php
$builder->withSessionTtl(86400);
```

Comportamento:

```text
sessão ativa
→ continua conversa

sessão expirada
→ novo ciclo de atendimento
```

E indicador:

```text
session.is_first_message
```

## Implementação

API pública aditiva:

```php
GuicheBuilder::withSessionTtl(int $seconds): self
```

Runtime interno:

```text
SessionLifecycleManager
```

Estados:

```text
new
active
expired
```

Campos enviados ao provider quando habilitado:

```text
session.status
session.is_first_message
session.is_new_cycle
session.was_expired
session.cycle
session.ttl_seconds
session.started_at
```

## Expiração

Preserva:

```text
execution_context
```

Reinicia:

```text
intent
state
messages
tool_history
usage do ciclo
```

Mantém apenas resumo não sensível de `previous_cycle`.

## Safety

- cache READ não atravessa ciclo expirado;
- replay de WRITE não atravessa ciclo expirado;
- Trusted Parameter Binding continua usando identity/tenant preservados;
- lifecycle roda antes de StateManager/gate/cache/replay;
- sem TTL configurado, comportamento legado permanece intacto.
