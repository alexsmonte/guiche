## Objetivo

Manter o reuso atual por `sessão + Tool + argumentos` e permitir que uma Tool `READ` declare fatos do contexto que também determinam a validade do resultado.

## Implementação

Metadata opcional:

```php
[
    'reuse' => [
        'depends_on' => [
            'state.exemplo',
        ],
    ],
]
```

Sem `reuse.depends_on`, a semântica anterior é preservada.

Com dependências:

1. o contexto atual gera uma assinatura determinística;
2. a assinatura é anexada somente à cópia persistida em `tool_history`;
3. um cache hit exige argumentos iguais e assinatura igual;
4. assinatura ausente, inválida ou diferente causa nova execução;
5. a entrada histórica não é apagada;
6. resultados antigos anteriores à Fase 05 não são confiados silenciosamente.

## Invariantes

- `WRITE` continua fora do cache genérico.
- replay/idempotência de `WRITE` não foi alterado.
- `ContextStoreInterface` não foi alterado.
- não houve novo método público no Builder.
- `withReusableTools()` continua sendo o opt-in de reuso.
- Trusted Parameter Binding continua acontecendo antes do cache.
- marker interno não chega à Tool, StateManager nem IA.
- o Core continua neutro de domínio.
