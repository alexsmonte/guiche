## Correção durante a migração

O primeiro run revelou uma suposição incorreta em
`tests/Integration/ResultProjectionTest.php`.

No cenário exclude-only, remover `raw.provider_payload` pode remover também o
contêiner `raw` quando ele fica vazio. Isso já era comportamento válido do Core.

A asserção PHPUnit foi corrigida para validar a ausência do caminho com
`isset()`, sem modificar `src/`.
